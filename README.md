# 🖥️ Yashi Yadav — AI-Powered Portfolio

A Windows-inspired interactive developer portfolio built with React, featuring an AI assistant that can answer questions about my skills, projects, experience, and background.

## ✨ Features

- 🖥️ Windows-style desktop interface
- 🤖 AI-powered portfolio assistant
- 💬 Streaming AI responses
- 🔍 Portfolio search
- 📄 Resume viewer
- 📁 Projects explorer
- 🌐 Published About Me website
- 🔗 GitHub and LeetCode shortcuts
- 📱 Responsive interface
- ⚡ FastAPI backend with Groq LLM integration

## 🤖 AI Assistant

The portfolio includes an AI assistant designed to answer questions about my professional background.

It can provide information about:

- Technical skills
- Projects
- Project roles and responsibilities
- Experience
- Technologies used
- Background

The assistant uses information from my resume, profile data, and project data and is instructed not to invent information when an answer is unavailable.

## 🚀 Featured Projects

### QueryMind

AI-powered natural-language-to-SQL assistant that converts user questions into SQL queries, retrieves information from a MySQL database, and generates natural-language answers.

**Tech:** Python, FastAPI, MySQL, Groq API, Pydantic, React

### AI-Based Farmer Query Support System

Smart India Hackathon project focused on providing an accessible agricultural advisory interface for rural users through multilingual text, voice, and image-based queries.

**Tech:** React, HTML, CSS, JavaScript, Figma

### Mental Health Score Prediction System

End-to-end machine learning web application that predicts mental health scores using lifestyle, social-media usage, and demographic features.

**Tech:** Python, FastAPI, Scikit-learn, Pandas, HTML, CSS, JavaScript

### MoodMate

AI-powered sentiment and emotion analysis project for analyzing user-provided text.

**Tech:** Python, Scikit-learn, Flask, React
